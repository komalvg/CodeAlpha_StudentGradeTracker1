# Student Grade Tracker

Student Grade Tracker is a console-based Java application designed to manage and analyze student academic performance efficiently. The system allows users to enter and store student names and grades using ArrayLists, making data management simple and dynamic.

The application calculates important statistics such as the average score, highest score, and lowest score, helping users gain insights into overall student performance. It also generates a detailed summary report displaying all students and their respective grades in a structured format.

This project demonstrates the use of core Java concepts including ArrayLists, loops, conditional statements, methods, user input handling with Scanner, and basic data processing. The application provides a user-friendly menu-driven interface, making it easy to add students, view records, and generate reports.

## Key Features

* Add and manage student records
* Store data using ArrayLists
* Calculate average, highest, and lowest scores
* Display a complete summary report
* Menu-driven console interface
* Input validation for grades
* Clean and organized Java code structure

## Technologies Used

* Java
* ArrayList
* Scanner Class
* Object-Oriented Programming Concepts

This project was developed as part of a Java programming internship to demonstrate fundamental programming skills and data management techniques.
